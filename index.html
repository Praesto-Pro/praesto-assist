    Good questions. Clear answers.

    You should know exactly what your team gets and when extra charges could apply.

    Do I need an IT person to use this?

    No. Praesto Assist Agent is built for small businesses without a dedicated IT person. Employees can ask in everyday language, and the Agent will investigate the issue on their enrolled computer.

    Can my employees ask for help directly?

    Yes. Give each employee an individual account and enroll their company-approved computer. They can ask Praesto Assist Agent for help rather than routing routine computer questions through you.

    Can Praesto Assist Agent fix every computer problem?

    It makes a best-effort attempt at any issue affecting an enrolled computer using the available tools and permissions. It cannot guarantee a fix. The examples above are not a restricted catalog, and it will not make destructive changes without review.

    Will it change settings without permission?

    Read-only diagnostics can run after identity and device verification. Before changing an employee's computer, the Agent requests their approval. Potentially risky steps require included technician safety review. The Agent does not perform destructive actions on its own, and a technician can reject an unsafe step.

    When would I pay extra?

    Only if the Agent cannot resolve an issue and you choose separately billed human troubleshooting or repair, or if you request paid assisted onboarding. An authorized company contact must approve the scope and cost before billable work begins. Technician safety review of an AI-proposed action is included.

    How does the $99/month pricing work?

    The first $99/month covers up to 10 enrolled computers. For 11-20 computers the price is $198/month, for 21-30 it is $297/month, and so on. Employee count does not affect the price. There is a one-block minimum while subscribed.

    Is this the same as fully managed IT?

    No. Praesto Assist Agent provides on-demand AI troubleshooting for enrolled computers. Proactive monitoring, scheduled patching, managed security, backups, IT projects, and an included human helpdesk are not part of this subscription.

    Is there a setup fee or long-term contract?

    You can self-onboard without an upfront setup charge. If you'd rather have help getting set up, assisted onboarding is quoted separately. The proposed plan is billed monthly; final cancellation terms will be shown before checkout.
